# Cluster Manager Component Diagram

Cluster Manager는 Aerospike CE 클러스터를 관리하는 Web UI입니다. Backend는 aerospike-py를 사용해 Aerospike 데이터에 접근하고, Kubernetes API를 통해 ACKO가 관리하는 cluster와 Pod 상태를 조회하거나 변경합니다.

| 컴포넌트 | 역할 |
|----------|------|
| Frontend | Next.js 14.2 App Router, React 18, Tailwind CSS 3.4, Zustand 상태관리, 클러스터 시각화 |
| Backend | FastAPI REST API, 비즈니스 로직 |
| aerospike-py (내장) | Backend에서 Aerospike 데이터 접근 (AsyncClient) |
| K8s Client | ACKO CRD 조회, Pod 상태 모니터링 |
| Database | 연결 정보, 사용자 설정 저장 |
