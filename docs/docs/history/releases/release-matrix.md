## 버전 관리 규칙

- **aerospike-py**: SemVer + pre-release (`dev`, `alpha`, `beta`, `rc`)
- **ACKO**: SemVer (v0.0.x = pre-stable, v0.1.x = feature-complete)
- **cluster-manager**: SemVer (ACKO 통합 기준)
- **plugins**: SemVer
- **Aerospike CE**: Aerospike Community Edition 서버 버전

## 호환성 보장 범위

- 같은 행의 version 조합은 통합 테스트를 완료했습니다.
- 서로 다른 행의 version을 조합했을 때의 호환성은 보장하지 않습니다.
- Aerospike CE version은 각 조합이 요구하는 최소 server version입니다.
- `-`는 해당 시점에 프로젝트가 아직 존재하지 않았음을 뜻합니다.
