## 변경 요약

편집 다이얼로그 UI와 관련 문서를 함께 정리했다. Cluster Manager 통합 경로에서 사용하는 다이얼로그의 동작과 안내 내용을 맞췄다.

## 주요 변경 사항

- 편집 다이얼로그 UI 개선
- 문서 명확성 향상
- Cluster Manager 통합을 위한 다이얼로그 관련 개선 추가

## 영향 범위

변경 범위는 ACKO UI 컴포넌트와 문서다. 사용자는 수정된 편집 다이얼로그를 사용하고, 관련 동작은 업데이트된 문서에서 확인할 수 있다.
